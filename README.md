# Product Catalog REST API

This is a Node.js and Express.js REST API for managing a small product catalog. Product data is stored in memory and resets whenever the server restarts.

## Features

- View every product
- Find a product by its ID
- Create a product
- Update one or more product fields
- Delete a product
- Filter products by category
- Validate incoming JSON data
- Return clear errors for missing IDs and categories

## Product format

```json
{
  "id": 101,
  "name": "Notebook",
  "category": "Stationery",
  "price": 85,
  "quantity": 40
}
```

`id` is generated by the API. `name` and `category` must contain at least two characters. `price` must be a non-negative number, and `quantity` must be a non-negative whole number.

## Installation

Node.js 18 or newer is required.

```bash
npm install
npm start
```

The API starts at `http://localhost:4000`. Open `http://localhost:4000/products` to see the initial products.

## Required routes

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/products` | List all products |
| GET | `/products/:id` | Find one product |
| POST | `/products` | Create a product |
| PUT | `/products/:id` | Update a product |
| DELETE | `/products/:id` | Delete a product |
| GET | `/products/category/:category` | Filter by category |

## Request examples

Create a product with `POST /products`:

```json
{
  "name": "Phone Stand",
  "category": "Accessories",
  "price": 350,
  "quantity": 18
}
```

Update selected fields with `PUT /products/101`:

```json
{
  "price": 90,
  "quantity": 35
}
```

## Tests

Run the automated test suite with:

```bash
npm test
```

The tests cover all required routes, validation, category filtering, missing-resource errors, and the create-update-delete lifecycle.
